FLAGSHIP · SOFTWARE ENGINEERING / AI01

FraudNetZW

A hybrid fraud-detection system for Zimbabwean mobile-money transactions.

FraudNetZW brings multiple analytical signals together in an analyst console to help identify potentially suspicious transactions and prioritise review. I designed and built this academic project as a full-stack system, connecting a React/Vite dashboard to a Python/FastAPI backend and detection services.

ReactVitePythonFastAPIFirebaseScikit-learnNetworkX

Engineering notes ＋

Objective

Explore how multiple fraud indicators can support a clearer analyst review workflow.

Approach

A transaction service coordinates rule, behavioural, ML and graph signals, then presents the assessment in an analyst-facing console. The project is an academic prototype, not a production financial service.

My role & learning

Independent project work across frontend, API integration, detection layers and product workflow. It strengthened my full-stack system design and my understanding of combining explainable rules with statistical and relational signals.
